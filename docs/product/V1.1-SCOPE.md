# AI Live Copilot V1.1 scope

## In scope

1. Product data import from links, PDFs, OCR, and manual input.
2. Product knowledge base and structured extraction.
3. Product comparison and advantage extraction.
4. AI livestream script generation.
5. Evidence-based factual verification.
6. Script editing and version management.
7. Travel as the first industry module.

- Cloud ASR.
