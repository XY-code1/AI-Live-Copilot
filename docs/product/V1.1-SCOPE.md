# AI Live Copilot V1.1 scope

- **Status:** Accepted
- **Date:** 2026-11-14 (amended 2026-11-16)
- **References:** [TECH-STACK.md](../TECH-STACK.md) · [ADR 0001](../adr/0001-v1.1-architecture.md) · [ADR 0002](../adr/0002-file-processing-and-async-boundaries.md)

## In scope

1. Product data import from links, PDFs, images/OCR, and manual input.
2. Product knowledge base and structured extraction into a canonical product schema.
3. Product comparison and advantage extraction with evidence pointers.
4. AI livestream script generation.
5. Evidence-based factual verification (claim → source).
6. Script editing and version management.
7. Travel as the first industry module.

## Out of scope

- Real-time livestream assistant.
- Windows desktop client (Tauri 2).
- Cloud ASR.
- Full multi-tenant permission and billing system (reserve `user`/`workspace` fields only).

## MVP acceptance criteria

- A user can import one travel product from a URL, PDF, or image and see a structured product record in the UI.
- The structured record is stored in PostgreSQL with source provenance.
- AI-generated attributes and selling points are validated against Pydantic schemas, with bounded retry on malformed output.
- A generated script can be checked against the source and unsupported claims are surfaced.
- Core flows are covered by pytest, ESLint, and `tsc`, run in CI.

## Deliberately deferred

Redis/Celery async jobs, pgvector/RAG, OCR execution-model choice (to be settled before pipeline implementation), AI evaluation and observability tooling, and all desktop/realtime work. See [`../TECH-STACK.md`](../TECH-STACK.md) for stages.
