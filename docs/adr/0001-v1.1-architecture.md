# ADR 0001: V1.1 architecture baseline

- Status: Accepted
- Date: 2026-11-14

## Decision

Use Next.js for the web application and FastAPI for the API. PostgreSQL is the system of record. AI calls go through a provider adapter, with DeepSeek as the first provider. Industry-specific rules remain outside the shared AI core.

Redis and Celery are not required for initial synchronous flows; they may be enabled when measured workloads require retries, concurrency control, or durable background jobs.

## Consequences

The repository is a small monorepo with independently deployable web and API applications. Provider-specific behavior must not leak into product-domain services. Source evidence and generated content must remain traceable across versions.
