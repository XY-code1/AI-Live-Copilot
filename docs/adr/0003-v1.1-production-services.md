# ADR 0003: V1.1 production services

- Status: Accepted
- Date: 2026-11-17

## Decision

Use Clerk for identity, PaddleOCR CPU for image text recognition, Render Blueprint/Docker for the initial cloud deployment, and Sentry plus structured JSON logs for observability.

Local development uses a clearly separated `AUTH_MODE=dev`; production uses Clerk JWT verification. Redis and Celery remain deferred until measured workloads require durable background execution.

## Consequences

The MVP can run locally without external authentication configuration while the production service has real identity and workspace isolation. OCR increases the API image size and memory requirement; it remains behind an adapter so a cloud OCR provider can replace it later.
